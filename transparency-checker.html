What does this check?

Transparent images use an alpha channel. An alpha value of 255 is fully opaque, 0 is fully transparent, and values in between are partially transparent. This tool checks the decoded pixels rather than guessing from the filename.

PNG does not mean transparent

PNG supports transparency, but a PNG can still contain a solid white, black or coloured background. If every pixel is fully opaque, the image does not actually contain transparency even though the file extension is .png.
