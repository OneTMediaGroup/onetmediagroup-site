What is aspect ratio?

Aspect ratio describes the proportional relationship between width and height. A 1920 × 1080 image simplifies to 16:9. A 1080 × 1080 image is 1:1.

Avoid stretched images

If you change width without changing height proportionally, an image can look squeezed or stretched. Use the matching-size calculator to find the correct second dimension before resizing.
