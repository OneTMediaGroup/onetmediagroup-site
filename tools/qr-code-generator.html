What can a QR code contain?

A QR code can encode a website URL, plain text, contact information or other text-based data. This simple generator encodes exactly what you enter and does not create a tracked redirect or require an account.

Error correction

Higher error correction can make a QR code more tolerant of small amounts of damage or obstruction, but it also makes the code denser. Medium is a sensible general-purpose default.
