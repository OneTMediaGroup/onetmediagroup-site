How it works

  1. Choose one image or a batch.
  2. Set the quality. 82% is a useful starting point for photos.
  3. Compress, compare the sizes and download your results.

Good to know

JPG and WebP respond well to adjustable quality. PNG is lossless, so some PNG files may not shrink much when re-encoded. The tool tells you the real before-and-after size rather than pretending every file got smaller.
