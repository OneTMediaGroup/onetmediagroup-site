Image ready. The first AI run may take longer because the model files need to load into the browser.
Privacy: the selected image is processed in the browser by the background-removal library. One T does not need to receive the image for the removal operation. The browser must download the AI model/library assets, so the first use can be significantly slower than later runs and may use substantial memory on older devices.

AI, not a colour eraser

This tool attempts to understand the foreground subject rather than simply deleting white or green pixels. Results are usually strongest when the subject has a clear outline and reasonable contrast from the background.

Transparent PNG output

The finished file is exported as PNG so transparent areas remain transparent. Fine hair, glass, shadows, smoke and very complex edges are difficult segmentation cases and may not always be perfect.
