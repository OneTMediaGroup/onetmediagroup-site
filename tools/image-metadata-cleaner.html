Images

What “clean copy” means: the tool decodes the visible image pixels and creates a new image file from those pixels. That normally removes embedded EXIF and similar source-file metadata because it is not copied into the new file. It does not alter information visibly baked into the image itself.

Why clean image metadata?

Photos can contain extra information beyond the visible pixels. Depending on the source, that can include camera details, timestamps, editing information and sometimes location-related EXIF data. A freshly encoded copy is useful when you want the picture without carrying the original file's embedded metadata forward.

This tool does not claim to identify every possible metadata field. Its privacy feature is the clean re-encode: visible pixels in, fresh image file out.

What you can inspect here

  • Image dimensions
  • File format
  • Original file size
  • Transparency capability/result where applicable
  • Clean-copy file size

The browser deliberately does not expose every EXIF field through its normal image APIs, which is why cleaning by re-encoding is simpler and more dependable than pretending we can display everything.
